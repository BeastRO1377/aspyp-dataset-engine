# Concepts

## Evidence
A verifiable observation originating from an external source, stored with enough provenance to understand where and when it was observed.

## Provenance
Metadata describing the origin, acquisition time, source, and integrity context of an evidence item.

## Entity
A domain object that can be referenced by evidence and connected to other objects in the graph.

## Relationship
A typed connection between two entities, optionally supported by evidence.

## Dataset
A structured, analysis-ready collection derived from evidence and graph state.

## Derived signal
A value computed from public evidence or dataset fields. Proprietary ASPYP scoring logic is not part of the public scope.

## Principle
Evidence and derived interpretation should remain distinguishable. Derived results should be traceable to the observations on which they depend.
