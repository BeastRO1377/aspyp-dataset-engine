# Changelog

## 0.2.0 — 2026-10-10

- Add dependency-free `evm-transfer/v1` normalization and source provenance.
- Preserve integer raw amounts and serialize them as decimal strings.
- Validate EVM identifiers, asset consistency, integers and timezone-aware timestamps.
- Reject negative timestamps and malformed or oversized decimal input consistently.
- Add synthetic tests, an offline example, installation instructions and wheel checks.
- License the public code under Apache-2.0.
- Add a dated Etherscan capabilities review and distinguish code licensing from data rights.

## 0.1.0

- Initial public package foundation and public/private scope documentation.
