# Contributing

Contributions should improve general-purpose open-source data and graph infrastructure. Do not submit proprietary ASPYP datasets, private models, credentials, customer information, or commercial decision rules.

Before a pull request:

1. Explain the problem and proposed change.
2. Add or update tests where applicable.
3. Keep public interfaces documented.
4. Use synthetic or publicly redistributable fixtures.
5. Check that no secrets or private data are included.

If a change depends on proprietary ASPYP knowledge, publish the general-purpose technical concept rather than the proprietary implementation.
