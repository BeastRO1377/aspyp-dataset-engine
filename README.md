# ASPYP Dataset Engine

Open-source evidence and graph infrastructure for blockchain intelligence and AI-agent transaction verification.

## Status

Early public foundation (v0.1). Production ASPYP intelligence, proprietary datasets, private models, and commercial decision logic are intentionally excluded.

## Public pipeline

**Blockchain data → Evidence → Entities → Graph → Dataset → Analysis**

The engine is designed to work with independently sourced data and user-provided datasets.

## Public scope

- blockchain data collectors and adapters;
- evidence and provenance handling;
- normalization primitives;
- graph data structures and traversal;
- dataset schemas and transformations;
- generic entity representations;
- public analysis interfaces;
- tests, examples, and synthetic fixtures.

## Out of scope

Private ASPYP datasets, private entity-resolution mappings, commercial risk formulas and thresholds, proprietary behavioural models, private reputation data, authorization/settlement/recovery mechanisms, credentials, and production secrets.

See `docs/` for the public architecture and security boundary.
